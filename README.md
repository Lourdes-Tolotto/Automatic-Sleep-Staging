# Automatic Sleep Staging

Machine learning project for automatic sleep stage classification using physiological signals from polysomnography recordings.

The current pipeline includes signal preprocessing, handcrafted feature extraction, classical machine learning baselines, and gradient boosting models.

## Objective

The objective of this project is to classify each 30-second polysomnography epoch into one of five sleep stages:

- Wake
- N1
- N2
- N3
- REM

## Current pipeline

1. Dataset exploration
2. Signal preprocessing and quality control
3. Resampling and filtering
4. Epoch selection and normalization
5. Handcrafted feature extraction
6. Subject-level train and test split
7. Classical baseline evaluation
8. Gradient boosting model comparison
9. Holdout evaluation on unseen subjects

## Notebooks

The notebooks should be executed in order:

- `01_data_exploration.ipynb`: initial dataset exploration
- `02_preprocessing.ipynb`: signal preprocessing, quality control, filtering, resampling, and epoch selection
- `03_feature_engineering.ipynb`: extraction and analysis of handcrafted features
- `04_classical_baseline.ipynb`: evaluation of classical machine learning baselines
- `05_gradient_boosting_models.ipynb`: comparison of XGBoost, LightGBM, and CatBoost

## Dataset

The current processed dataset contains:

- 151 subjects
- 127,904 valid 30-second epochs
- 7 physiological channels
- 193 handcrafted features per epoch

The train, validation, and test partitions are created at subject level to prevent epochs from the same subject from appearing in both training and evaluation sets.

## Current results

The classical baseline notebook evaluates models such as SGD and Random Forest.

The gradient boosting notebook compares:

- XGBoost
- LightGBM
- CatBoost

Among the evaluated configurations, LightGBM obtained the best Macro-F1 score on the holdout set:

- Accuracy: 0.756
- Balanced accuracy: 0.746
- Macro-F1: 0.738

N1 remains the most difficult sleep stage to classify.

These results are preliminary and correspond to the current feature-based modeling stage.

## Current status

This repository contains a preliminary end-to-end implementation of the classical machine learning pipeline for automatic sleep staging.

Planned improvements include:

- analysis of subjects with high artifact rejection rates
- improved experiment reproducibility
- preservation of temporal epoch information
- inclusion of temporal context between consecutive epochs
- additional hyperparameter tuning
- sequence-based deep learning models
